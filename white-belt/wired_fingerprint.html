Lab Assignment: Onboard a Wired Device Using the Fingerprint Rule

📌 Objective

Automatically onboard a wired device based on its fingerprint (OS/device type) by applying fingerprint-based rules, without requiring 802.1X or manual registration.

🔧 Task Instructions

Step 1: Segment Reuse & Update

  • Navigate to Network Setup → Segments.
  • Locate the previously created 802.1X segment.
  • Rename it to something more generic (e.g., Wired-Fingerprint-Segment).
  • Remove the authentication method (set it to blank).
  • Confirm that it still has a Nile DHCP scope attached.

Step 2: Fingerprint Rule Setup

  • Go to Access Management → Add Device Rule.
  • Create a rule based on device fingerprint:
    • For example, select Windows OS or macOS as the match criteria.
    • Assign the device to the updated wired segment.
    • Set the rule to Auto-Approve.

Step 3: Device Connection

  • Connect your wired laptop or desktop to the switch.
  • The system should detect and classify the device using fingerprinting.
  • The device should automatically appear in the correct segment without any user action.

✅ Verification Criteria

Ensure the following conditions are met before considering the lab complete:

  • Device is fingerprinted and recognized correctly.
  • Auto-approved rule is triggered and device is placed in the updated segment.
  • Device appears in Access Management → Devices with its type (Windows/macOS) and correct segment.
