Lab Assignment: Onboard a Wired Device and Enable Lock-to-Port

📌 Objective

Automatically onboard a wired device and bind its approval to the specific switch port where it first connects, enhancing location-based security without requiring manual intervention or 802.1X authentication.

🔧 Task Instructions

Step 1: Network Segment Update

  • Navigate to Network Setup → Segments.
  • Locate the segment intended for wired device connections.
  • Ensure that the segment has a Nile DHCP scope attached.

Step 2: Lock-to-Port Configuration

  • Go to Network Setup → Access Management → Add Device Rule.
  • Create a rule based on device MAC address and fingerprint:
    • For example, select MAC address or device fingerprint as the match criteria.
    • Assign the device to the correct segment.
    • Enable the "Lock to Port" feature.
    • Set the rule to Auto-Approve.

Step 3: Device Connection

  • Connect your wired device (e.g., laptop, desktop) to the switch.
  • The system should detect the device and bind its approval to the specific switch port.
  • The device should automatically appear in the correct segment and be locked to its initial connection port without any user action.

✅ Verification Criteria

Ensure the following conditions are met before considering the lab complete:

  • The device is recognized and placed in the correct segment.
  • Lock-to-Port feature is successfully activated, ensuring the device remains bound to the initial port.
  • Device appears in Access Management → Devices with its MAC address, type, and locked port details.
